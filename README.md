# MINI-WMS
Aplicação Mini WMS desenvolvida para gerenciamento e automação de rotinas logísticas e controle de estoque.
Funcionalidades
Controle de estoque
Cadastro de produtos
API REST
Gestão logística
Tecnologias
Java
Spring Boot
Git
GitHub
Estrutura
backend/ frontend/ src/



Como executar
Pré-requisitos
Java 17+
Maven
Git
Instalação
Clone o projeto:

git clone https://github.com/ALEXOROSCO/MINI-WMS.git
Entre na pasta:

cd MINI-WMS
Execute:

mvn spring-boot:run
A aplicação estará disponível em:

http://localhost:8080
